日期：2026-10-27。基于 `1e2f7bb` 工作区。对应[GitHub Skills 调研](github-skills-review-2026-10-27.md)。

## 已实现

`scripts/build_report.py` 的 `replace_paragraph_text()` 改为只修改匹配的普通文本节点；所有正文、表格占位符调用者使用精确匹配范围。支持单个或跨 run 占位符、重复标记、三种既有括号格式，以及包含空格、XML 特殊字符、制表符和换行的替换值。新文字继承首个匹配 run 的格式，非目标格式、图片、字段和链接保留。

Word 拼写检查标记保持原样，不阻断普通文本匹配。字段内部及跨图片、超链接、修订等非文本边界的可见匹配会明确失败；跨段落字段也受保护。构建失败发生在保存之前，不覆盖已有输出或模板。未新增后端或依赖。

表格填充优先使用显式占位符，避免标签映射吞掉同段说明；合并单元格不会误把标签自身当作邻接值。没有显式标记时，仍按原有接口把邻接单元格第一段当作完整值；说明文字与值共段时应使用显式标记，并从原模板重建。

5. 复杂边界与跨段字段失败；真实 CLI 构建成功时保留素材，拒绝时原模板和已有输出字节不变。
