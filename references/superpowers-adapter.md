# Optional Superpowers integration

Superpowers is not a dependency of this report skill. Load it only when explicitly requested or when a specific available skill directly resolves the current task. Its absence requires no extra intake or fallback transcript.

Keep SKILL.md's single source-first workflow and shared repair budget. Delegation follows `multi-agent-workflow.md`; Superpowers must not add a second plan, extra worker or nested review loop. For a defect, inspect the source/artifact, fix the root cause and run the affected check. For completion, report observed verification and missing evidence accurately.
