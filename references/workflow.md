# Workflow

SKILL.md is the authoritative workflow and repair budget. This reference only covers conditional branches; do not load it for routine tasks.

## Experiments

Verify the required behavior on the chosen runtime. Linux-specific tasks require Linux/WSL or an existing VM/remote runtime; macOS POSIX compatibility is not proof of Linux equivalence. Use saved data/logs for report rebuilds. Long jobs run independently of the session. Missing results remain missing; never invent them.

## Screenshots

Capture the intended visible application/page/terminal with enough context. Preserve raw captures before annotation. Inspect for login/error/CAPTCHA/wrong-tab captures. PDF page renders and images made from logs are not real application screenshots.

## AI figures

Only after explicit AI permission/count and the conditional PPT-reconstruction answer, read ai-image-prompting.md and use the available image tool/skill under its current instructions. Plan conceptual content, labels and directional relationships before generation. Check once in the rendered report, batch defects, and use the shared repair budget. Keep provenance outside report prose unless academically required. AI figures cannot substitute for measured results. For selected PPT reconstruction, follow ppt-figure-reconstruction.md; the direct-raster one-pass rule does not apply to native-object rebuilding.

## Completion

Use the selected-format build and relevant QA. Follow `multi-agent-workflow.md` for adaptive delegation and first-use settings. The assigned reviewer covers the actual full artifact once; repairs cover affected content and downstream pagination/references. Do not add a Superpowers chain or duplicate main-agent review. Stop when checks pass or the shared budget/blocker requires a pending handoff. Preserve source and state limitations accurately.
